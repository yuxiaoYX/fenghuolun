## D01 产品定位 — 锁定

仓库名 `fenghuolun`。产品名 **风火轮**，界面大字 **风火轮**。副题「哪吒 L 车况账本 · 车友自制」。「账本」只作功能隐喻（电/油历史、补记、落库），不再当产品名或桌面图标名。

对外一句话：面向 **哪吒 L** 车主的开源工具箱，改善官方 App 不好用的只读车况与能耗展示，并把历史留在自己的服务里。

哪吒 L（`modelCode=EP32`）是 **第一个适配器**（`sourceId: "neta"`），不是永久产品名。以后加车型只加 source，不新开产品。

不是第二个「车况雷达」网站。禁止抄它的 UI、会员、轨迹、分享、续费。

## D02 用户角色 — 锁定

| 角色 | 使用端 | 说明 |
|---|---|---|
| 车主 | 仅前台 `apps/owner` | 看自己的车、填官方 `refresh_token`、触发同步 |
| 管理员 | 仅后台 `apps/admin` | 运维本服务：绑定列表、同步失败、脱敏日志 |
| 系统 | `server` | 换票、拉官方数据、落库、鉴权 |

车主界面不出现管理功能。管理界面不承担车主看车。禁止用「隐藏菜单」代替鉴权。

## D03 旧原型可整仓重构 — 锁定

当前根目录 Vite + Vue3 前台只是想法验证。**允许不保留任何现有代码。** 不迁移 `src/` 组件，不迁就错误 mapper / 错误代理。下一阶段按本文档新建 `apps/`、`server/`。

## D04 车主前台技术 — 锁定

车主前台用 **uni-app x**，开启 **蒸汽模式**（Vue Vapor 编译，不是 Steam 皮肤、不是游戏风格）。

- 语言：uvue + UTS
- 目标端：以 App（Android / iOS）为主，H5 能跑则跑，不能用 H5 缺能力倒逼蒸汽模式关闭
- 禁止把管理员后台做成 uni-app x
- 蒸汽模式具体开关以当时官方 uni-app x 文档为准，写在 `apps/owner` 的 manifest / pages 配置里

## D05 管理员后台技术 — 锁定

管理员后台：Vue 3 + Vite + TypeScript，普通 Web，仅管理员可登录访问。

## D06 后端技术 — 锁定

后端：**Go + GoFrame v2**（`github.com/gogf/gf/v2`）。

| 用 GoFrame 的 | 不用 GoFrame 的 |
|---|---|
| HTTP（`ghttp`）、中间件、配置、校验、日志 | 官方协议解码（仍在 `internal/neta`） |
| 落库时用 `gdb` + SQLite 驱动 | gf-vue-admin / 代码生成后台模板 |
| 定时同步用 `gcron`（第 2 期） | Casbin 全套 RBAC（管理员只有一种角色） |

车主会话与管理员会话仍是两套中间件，框架不合并它们。

官方协议解码放在 Go 内部包（`internal/neta`），不放在浏览器、不放在 uni-app 里直连官方。

默认存储：**SQLite**（单二进制自托管）。表结构保持常规 SQL，不绑死 SQLite 专有类型，以便以后加 PostgreSQL。驱动用 `github.com/gogf/gf/contrib/drivers/sqlite/v2`（pure go，无 cgo）。每张表有 `created_at` / `updated_at` / `deleted_at`（unix 秒），由 gdb 在 Insert/Update/Delete 时自动维护，禁止手写。业务时刻（`fetchedAt` / `reportedAt` / `syncedAt`）仍是独立字段，见 D15。

## D07 车主接入方式 — 锁定

暂不开发本产品的用户注册/密码登录页，也不开发官方短信验证码登录页。

车主流程：

1. 在前台填写自己从官方 App 取得的 `refresh_token`（界面文案就用这个名字）
2. 后端换取 Access Token
3. 查询当前车辆
4. 拉取车况与官方能耗
5. 车主不填写官方网关、签名算法、路径，不自己维护 Access Token

换票若返回新的 Refresh Token，必须保存新值。失效时提示重新填写，**不**自动回退到短信登录。

## D08 本服务会话 — 锁定

「暂不开发用户登录」≠ 公网裸奔。

- 车主：绑定成功后由 **本服务签发车主会话**（token / 安全存储），之后请求只带本服务会话，**客户端不再保存官方 Access Token**
- 管理员：独立的管理员账号密码（环境变量引导初始化），与车主会话完全分离
- 所有读车、同步请求必须在服务端校验 **会话 ↔ 车辆归属**

## D09 浏览器 / 前台不直连官方 — 锁定

车主 App、H5、管理员 Web **从不**直连 `chehezhi.cn` 等官方主机。官方通信只发生在 Go 适配器。现有 Vite `api-official` 代理是原型，重构后删除。

## D10 官方接口与第三方接口分离 — 锁定

哪吒官方 App 接口（HAR 证据）与任何第三方网站（含车况雷达）的接口、字段、路径、userId 规则 **禁止混用**。`vehicleId`、VIN、官方账号 id 是不同字段。

## D11 不做 OTA、不宣称续命车机 — 锁定 / 禁止

本项目 **不能**、也 **不得宣传** 替代哪吒官方 OTA / 车机系统更新。App 云接口不是固件通道，没有厂商签名密钥就不能刷写车机。品牌停更与云接口能用多久是两件事。

## D12 远程车控 — 禁止（直到有闭环证据）

解锁、闭锁、空调、充电控制、座椅、冰箱、哨兵等：配置里出现能力名 **不等于** 已掌握下发路径与回执。当前阶段 UI 可灰色占位，**禁止** 对实车发写命令。要做必须先有：路径、参数、鉴权、执行结果 的抓包或实车对照，并改本文件解除本条。

## D13 数字钥匙 / 蓝牙钥匙 — 禁止

HAR 中的钥匙原始数据、MQTT、证书申请不得进入开源样本，也不得做成「Web 数字钥匙」。纯 H5、原生 App、蓝牙钥匙分别评估；默认不做。

## D14 未知值保持未知 — 锁定

官方字段单位、枚举、偏移未对照实车前：

- 显示 `—` / `unknown` / `null`
- **禁止** 把未知充电状态显示成「未插枪」
- **禁止** 用总里程顶替纯电里程当分母
- **禁止** 把 `255` / `65534` / `65535` 当正常物理量运算
- **禁止** 用 `bms*` 字段相除后宣称 SOH

## D15 时间必须拆开 — 锁定

至少保存并展示：

- `fetchedAt`：本服务拉到的时间
- `reportedAt`：车辆上报时间（如 `vehicleConnection.reportTime`）

禁止只用本机 `now` 冒充车况新鲜。拉取成功 ≠ 数据新鲜。

`fetchedAt` **不是** GoFrame gdb 的 `created_at`。后者是行插入时间（本仓落库也还没走 gdb 自动时间字段）；前者是「这次从官方云拉到车况」的业务时刻，快照表按它去重、油耗差分按它划段，禁止删掉或用行生命周期字段顶替。

## D16 能耗：电和油都要，但来源不同 — 锁定

哪吒 L 是增程车。能耗页 **必须同时记账耗和油耗**，不能只展示官方 kWh。

两条账分开，禁止混成一个「综合油耗」当主数字：

| 账 | 来源 | 规则 |
|---|---|---|
| 电耗 | 官方能耗统计（行驶 / 空调 / 回收 / 风阻 / 附件，kWh） | 不把 kWh 换算成升 |
| 油耗 | 本服务用连续快照的 `fuelPct`（及油续航）差分 | 油量上升记为加油，不计入消耗；油箱容积未对照前，升数可标「约」或只显示百分点 |

HAR **没有** 官方用油升数、纯电里程、增程里程。禁止把官方能耗接口塞进旧 `EnergySegment` 再补 0 冒充油耗。没有分母就不算 L/100km；有油量差就可以先记账耗油。

## D17 位置与轨迹 — 锁定

官方车况里存在经纬度。**修订（2026-09-10，用户决策）**：实现「单点位置」——解码器从 `vehicleExtend.lng/lat`（÷1e6，WGS-84）读取**最新一个点**，落库于 binding 表的 `lng/lat/loc_reported_at` 列（每次同步覆盖，不存历史轨迹），车主 App 与管理员 Web 均可见。前台在「车身与轮胎」卡片总里程下方展示经纬度。**仍不做行驶轨迹回放**（那需要历史序列，属另一决策）。原「默认不采集不落库」作废。

## D22 时间只按北京时间对外 — 锁定

产品只面向中国用户，不做国际化。

- 对外 JSON（`fetchedAt` / `reportedAt` / `syncedAt` / `fromAt` / `toAt` / `location.reportedAt`）一律是北京时间 `YYYY-MM-DD HH:mm:ss`（`Asia/Shanghai`），零值为 JSON `null`
- 前台只展示字符串，**禁止**再把 UTC/`Z` 换算成当地时间
- 库内列继续用 unix 秒；快照 payload 与 API 同格式，读入时仍接受旧 RFC3339

| V6 | 多车列表 | HAR 只有「当前车辆」 |
| V7 | 蒸汽模式在目标 uni-app x 版本上的平台支持矩阵 | 以当时官方文档为准 |
| V8 | 哪吒 L 油箱容积、油量百分比刻度 | 用于把 `fuelPct` 差分成升；未对照前界面以百分点为主 |
