风火轮 v4 · 继续打磨

「风火轮」= 哪吒的座驾：踩上就走、出门够不够。哪吒身份放副题和关于页，主名中性、不被品牌绑死。补记入口在能耗页悬浮「＋」，第五 tab 是「我的」。

这版的变化

  • 命名：App 名「风火轮」，副题「哪吒 L 车况账本 · 车友自制」。仓库 / Go module：`fenghuolun`。显示名与工程名已同步。
  • 补记入口：能耗页悬浮「＋」→ 弹出「记充电 / 记加油」。记账是高频动作，不藏在设置里。
  • 「工具箱」→「我的」：车辆资料卡（VIN、绑定状态、四本账笔数）+ 记账设置 + 数据 + 账号，车企 App 惯例语义。
  • 记录卡可点：能耗页充电/加油记录点击有反馈（高保真阶段展开完整明细）。
  • 首页仍是：答案条 → 2.5D 车视图 → 解锁滑轨 + 锁车 → 12V/油量。
