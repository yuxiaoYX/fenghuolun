# 产品

## 一句话

给哪吒 L 车主用的开源工具「风火轮」：用官方 App 同一套云接口，把车况和能耗展示得更清楚，并把历史留下来。管理员另有 Web 后台运维本服务。车主只使用前台。

## 为什么做

哪吒 L 车主仍要日常看电量、续航、充电、能耗。官方 App 体验不便，品牌后续 OTA 与运营不确定。本项目 **优化云接口之上的使用体验**，不是给车机做非官方系统更新。

## 谁用

- **车主**：自己的车、自己的官方 `refresh_token`。安装或打开前台即可。
- **管理员**：部署者。看同步是否失败、绑定是否异常。不代替车主看车。
- **贡献者**：按 `docs/` 扩适配器与解码，不把密钥与 HAR 带进仓库。

## 车主要能做什么（目标体验）

1. 填写 `refresh_token`，绑定成功后看到 **当前车辆**（哪吒 L / EP32）
2. **车况**：俯视车图 + 胎压胎温、门/后备箱、电量、纯电续航、综合续航、油续航（有增程才显示）、温度、充电状态、12V（折叠）、胎压（单位已验证才显示数字）；位置只显示最新一点（无地图）
3. 能区分「刚刚同步成功」和「车上报时间已经过了很久」（上报超过 2 小时标陈旧）
4. **能耗**：电和油并列。电走官方 kWh 分项；油走本服务对油量变化的记录。增程车不能只有电耗页
5. **电池**：只展示有证据的电压/电流/温度；没有 SOH 证据就空着
6. **历史**：本服务落库的快照与能耗，官方云停之前能一直累加
7. 远程控制在「车况」和「车控」可见但禁用，文案说明尚未开通，点击不发请求

## 明确不做

| 不做 | 原因 |
|---|---|
| 官方短信登录页 | 决策 D07 |
| 车主注册/密码体系（一期） | 用 refresh_token + 本服务会话 |
| OTA / 刷写车机 | 做不到，也不许宣传 |
| 远程车控 | 无命令闭环 |
| 数字钥匙、蓝牙钥匙 | 敏感且端能力不够 |
| GPS 轨迹、行程 polyline | 产品拒绝抄车况雷达；只留最新一个点（D17） |
| 会员、分享海报、续费 | 开源自用工具 |
| 把未知值显示成确定状态 | D14 |
| 浏览器直连官方 API | D09 |

## 成功标准（产品层）

- 车主不理解签名、PKI、网关，也能完成绑定与看车
- 任一数字都能回答「来自哪条官方字段、经过什么换算、不确定时为什么是 —」
- 管理员能在不看到明文 refresh_token 的情况下判断同步健康度
- 开源克隆者按文档自托管后，只用自己的 token 能跑通只读路径
