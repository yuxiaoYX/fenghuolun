# 车主前台线框图

实现以 [`hifi-v2.html`](hifi-v2.html) 为准（深色座舱夜航 / 浅色晨雾提车；车主 App 默认浅色，可在「我的」切换深色）。

早期结构稿：[`owner.html`](owner.html)。v1 高保真见 [`hifi-v1.html`](hifi-v1.html)。

官方 App 是控车面板。风火轮的差别：

| 页 | 官方常见做法 | 风火轮 |
|---|---|---|
| 车况 | 大车图 + 电量 + 远程三键 | 俯视示意 + 续航/里程/温度/充电；解锁滑轨可见但禁用 |
| 车控 | 真下发 | 灰色占位，无命令闭环前不发写 |
| 能耗 | 几乎只有电的分项图 | 电（官方 kWh）和油（油量差分）并列；花费无接口则空着 |
| 电池 | 几乎没有可用健康度 | 12V、同电量包电压；SOH / 容量估算空着 |
| 我的 | 账号商城 | 绑定、解绑、关于；记账设置占位 |

远程不发命令。车图只读，不接受车控点击。
