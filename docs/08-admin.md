# 管理员后台

路径：`apps/admin`。Vue 3 + Vite + TypeScript。只给管理员用。

## 谁能进

- 仅管理员会话
- 部署时用 `FENGHUOLUN_ADMIN_BOOTSTRAP_*` 创建第一位管理员
- 无「用车主 refresh_token 登录后台」
- 无公开注册

## 页面

| 路由 | 职责 |
|---|---|
| `/login` | 用户名密码 |
| `/` | 总览：绑定数、今日同步成功/失败、上游连续失败 |
| `/bindings` | 绑定表：车型、脱敏 VIN、状态、最近同步 |
| `/bindings/:id` | 详情：状态机、最近 job、解码警告；无凭证明文、无完整官方响应 |
| `/jobs` | 同步任务流 |

总览页可停用绑定：只清本服务车主会话，不向官方下发车辆命令。同步时间直接展示后端给的北京时间字符串，不要在浏览器里换时区。

不做：远程车控面板、地图、车主模仿界面、编辑官方 token。

## 权限

前端路由守卫只是体验。所有敏感 GET/POST 以服务端管理员中间件为准。车主 token 访问 admin API 必须 403。

## 展示脱敏

- VIN：保留策略见 `10-security.md`（例如只显示后 4 位）
- 错误信息：展示 `errorInternal` 前仍要过滤 Bearer、cookie、token 字段
- 禁止下载 HAR、禁止导出凭证明文

## 空壳完成标准（第 0 期）

- 登录页 + 空白总览
- 环境变量指向本地 Go
- 无任何官方接口调用
